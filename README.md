# Fire Golem - Blade & Sorcery 1.0 (PCVR)

A fire-elemental variant of the Dalgarian golem boss.

**Planned features**
- Fireball projectile that explodes on impact
- Lingering ground-fire zone that burns for a few seconds in a small area
- Special ability on a cooldown
- Remixed melee/ranged attack combos via a cloned brain

> Status: scaffold. Systems land in stages; nothing compiles against the
> B&S SDK until the SDK references are in place (see README in FireGolem/).
